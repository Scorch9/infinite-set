# infinite-set
Infinite set puzzles. Customize settings, train, and enjoy!
https://infinite-set.scorchscorch093.workers.dev/?puzzle=BDMDDDwiOz8CBxAjGQ

### How it works
Generate a fresh SET puzzle in your browser. Choose the board size and how many sets it should contain, find every set against the clock, and share a challenge link so others can play the same board.

### AI Usage
I used AI to implement this site, but did the deployment and design work myself. I proposed and approved all the project’s ideas and architectural decisions.
